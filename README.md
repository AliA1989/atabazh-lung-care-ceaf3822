# Atabazh Medical Website

Public website for Atabazh Medical Inc. and the Smart Lung Physio™ medical-device development program.

## Local development

```sh
npm install
npm run dev
```

## Validation

```sh
npm run build
npm run lint
```

## Technology

- React and TypeScript
- Vite
- Tailwind CSS
- Radix UI components

Smart Lung Physio™ is under development. Website product descriptions must not be presented as regulatory clearance or clinical efficacy evidence.
